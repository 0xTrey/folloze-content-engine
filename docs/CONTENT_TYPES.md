# Content Types

## Comparison

- Best for competitor and category decision queries
- Must include a TL;DR table and a direct recommendation

## Guide

- Best for strategic and educational search intent
- Must include a definition block and step-by-step structure

## FAQ

- Best for extractable answers and long-tail queries
- Must include self-contained Q&A blocks

## Glossary

- Best for category ownership and definitional queries
- Must open with a clear first-sentence definition
